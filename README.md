# 📊 FMCG Sales Data Analysis & Forecasting

## 📝 Project Overview
This project focuses on analyzing FMCG (Fast-Moving Consumer Goods) sales data using **Microsoft Power BI** and **Advanced Excel**. The primary objective is to build an interactive dashboard to monitor Key Performance Indicators (KPIs), visualize sales trends across different territories and brands, and forecast future sales. 

## 🎯 Key Objectives & Tasks Completed
This project is divided into two main segments: Power BI Dashboarding and Excel Data Summarization.

### 📈 Power BI Tasks:
1. **Data Modeling:** Imported raw dataset and established logical relationships.
2. **Interactive Filters:** Created slicers for Area, Territory, Category, and Brand.
3. **KPI Cards:** Displayed Total Sales Value, Total Sales (in Tons), and Average Price per Ton.
4. **Visualizations:**
   - Territory-wise Sales (Bar Chart)
   - Day-wise Milk Category Sales Trends (Line Chart)
   - Brand-wise Sales Distribution (Donut Chart)
   - Beverage Brand Sales (Clustered Bar Chart)
5. **Advanced Analytics:** Implemented Sales Trend analysis with **Forecasting for Jan '25**.

### 📊 Excel Tasks (Pivot Tables):
- Prepared a summary of `Sales_dp` by **Territory**.
- Prepared a summary of `Sales_dp` by **Category**.
- Prepared a summary of `Sales_dp` by **Brand**.
- Created a specialized Pivot Table exclusively for the **Happy Cow** brand's `Sales_dp`.

## 🛠️ Tools & Technologies Used
- **Microsoft Power BI:** For Data Cleaning (Power Query), Data Modeling (DAX), Dashboarding, and Forecasting.
- **Microsoft Excel:** For dataset storage and Pivot Table generation.

## 📂 Dataset Information
The dataset contains transaction-level sales data with the following key attributes:
- **Location:** Route, Area, Territory
- **Product Details:** Category, Brand, Product Name
- **Metrics:** Sales Quantity, Sales in Ton, Sales DP (Dealer Price), Discount.
